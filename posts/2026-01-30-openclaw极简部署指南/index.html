10 万星爆款！OpenClaw（前 Clawdbot/Moltbot）极简部署指南

OpenClaw（前 Clawdbot/Moltbot）两周冲上 10 万星。本文手把手教你用 Lima、OrbStack、WSL 等虚拟机安全部署这款本地 AI Agent，涵盖安装、配置、启动与聊天平台连接。

撰文Pengfei Ni

发布2026 年 01 月 30 日

阅读时间4 分钟

最近公众号总能看到 Clawdbot/Moltbot/OpenClaw 这个东西。两周冲到 10 万星，增速有点离谱。

有意思的是，这三个名字都是同一个项目，它在一个月内改了三次名字。先是叫 Clawdbot，因为和 Claude 太像被 Anthropic 律师函警告；然后社区投票改成 Moltbot，取名蜕皮的意思；到今天又改成了 OpenClaw，既保留了龙虾吉祥物的梗，又强调了开源属性。OpenClaw 的作者 Peter Steinberger 调侃，这可能是改名最频繁的开源项目。

今天这篇文章就带你一起看看，怎么用既安全又省钱的方式把它玩起来。

OpenClaw 是什么？

OpenClaw 是一款本地运行的 AI Agent，支持连接常用聊天工具，比如 WhatsApp、Telegram、Discord、Slack 和飞书等等。

普通聊天机器人记性差，聊完就忘。OpenClaw 不一样，它有长期记忆，能读写文件、执行终端命令、操作浏览器、收发邮件。结合社区丰富的 Skills，它几乎可以接管你在电脑上的所有操作。

OpenClaw 完全开源，所有数据都存储在本地，隐私可控。官方 Slogan 是：Your assistant. Your machine. Your rules。

因为 OpenClaw 需要独立的计算机环境+ 24 小时运行，许多人专门购买 Mac mini 作为专属服务器，也因此带火了 Mac mini。

当然，OpenClaw 也有很多争议，狂烧 AI Token、大量安全漏洞、随意操作计算机环境、容易被恶意软件诱导利用等等问题导致 OpenClaw 并不推荐直接部署到主力设备上。所以，我建议你只在虚拟机或者容器等独立安全的环境中使用。

接下来，看看如何部署一套你自己的 OpenClaw。

虚拟机环境准备

Lima（Linux/macOS）

Lima 是个轻量的 Linux 虚拟机管理工具，让你可以在 macOS 或 Linux 方便创建和管理虚拟机。Lima 的安装使用也比较简单：

brew install lima
limactl create --name=default template://docker
limactl start default

启动后用 limactl shell default 进入虚拟机。

OrbStack（macOS）

OrbStack 是 macOS 上更现代的选择，最初是 Docker Desktop 的轻量级替代，后来也支持创建和管理虚拟机了。

brew install orbstack

# 创建一个 Ubuntu 虚拟机
orb create ubuntu botvm

# SSH 登录虚拟机
ssh botvm@orb

WSL（Windows）

Windows 用户用 WSL 就行。建议新建一个 Ubuntu 发行版，和主力 WSL 环境分开。

wsl --install -d Ubuntu-24.04

装好后从开始菜单启动 Ubuntu，后续操作和 Linux 一样。

土豪方案

如果不想折腾本地环境，Cloudflare 有个托管方案叫 MoltWorker，$5/月，一键部署到 Cloudflare Workers。

具体步骤可以参考 https://github.com/cloudflare/moltworker。

安装 OpenClaw

虚拟机环境准备好之后，安装 OpenClaw 有两种方式。

方法一：官方一键脚本

图省事的话，你可以执行官方的一键安装脚本：

# Linux/MacOS
curl -fsSL https://openclaw.bot/install.sh | bash

# Windows
iwr -useb https://openclaw.ai/install.ps1 | iex

这个脚本会自动检测系统、安装 Node.js、配置环境、最后再安装 OpenClaw 。大多数情况下用这个脚本就行了。

手动安装

对于高级用户，如果你想自己控制 Node.js 版本等各种环境，也可以手动安装。

先装 nvm 和 NodeJS。

# 安装nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash

# 加载环境变量
\. "$HOME/.nvm/nvm.sh"

# 安装 Node.js
nvm install 24

# 验证安装成功
node -v

然后，再用 npm 安装 OpenClaw：

npm install -g openclaw@latest

配置与启动

装好之后，运行初始化向导：

openclaw onboard --install-daemon

向导会引导你一步步配置 OpenClaw，AI 大模型可以选择一个免费的，比如：

  • Provider 选择 QWen OAuth
  • 然后模型选择默认的 qwen-portal/coder-model

剩余其他配置可以全部跳过，后续需要的时候再让 OpenClaw 帮你配。

初始化完成后，选择打开 Web 浏览器，命令行会输出一个带有 token 的链接，比如 http://localhost:18789/?token=a7c2b7dc3da27059289c25211c17e4e428836184ab44226a，打开这个网址就可以跟 OpenClaw 进行聊天了。

注意：刚才提到的 Lima/OrbStack 这些虚拟机软件会自动帮你做好端口映射，所以你在主机也可以通过 localhost 访问，不需要公网 IP。

命令行使用

除了网页，你也可以直接在终端跟它对话。

# 终端 TUI（类似 Claude Code 的终端聊天界面）
openclaw tui

# 直接让 Agent 执行任务
openclaw agent --message "帮我整理一下今天的待办事项" --thinking high --session-id agent:main:main

连接聊天平台

OpenClaw 支持十几个聊天平台，包括 WhatsApp、Telegram、Slack、Discord 等等。前面你已经配置好了 AI Agent，所以就不需要自己配置了，直接在聊天里跟它说，让 OpenClaw 帮你配置即可。

比如，对 Telegram 来说，你可以直接问：

帮我配置 Telegram 连接

OpenClaw 会一步步配置，并在需要你操作的时候告诉你详细步骤。

写在最后

说实话，OpenClaw 玩下来感觉就是早期 K8s 的味道，能干很多事，但配置复杂，想要用起来，你得先被它折腾一顿。

我自己跑了几天，确实能帮忙干一些重复性的事情（整理 RSS 订阅、，但离 Jarvis 还有很大距离。如果你对 AI Agent 感兴趣，值得花点时间玩一下。但对日常工作内容来说，Claude Code + Skills 这类更成熟的方案更适合。
